# @x12i/graphenix-logic usage example

Graphenix runtime logic: path resolution, variable assignment, and condition evaluation for graph execution.

This consuming application demonstrates **evaluate simple and combined graph conditions** using the published npm package, pinned to `2.17.0`.

## Run

Requires Node.js 24 or newer and npm. The example needs no service credentials.

```sh
npm install --ignore-scripts
npm start
```

## Example

[`src/index.mjs`](src/index.mjs) contains the complete example. Assertions check the demonstrated behavior and the program prints a small result.

## When to use the package

- Resolve paths and evaluate graph conditions during execution.
- Apply variable assignments through the runtime logic engine.
